│ Что делать дальше, в таком порядке:                                          │
│                                                                              │
│ 1. Вычислите пороги в CI, в том окружении, где будут запускаться тесты       │
│    (время, измеренное на ноутбуке, не переносится). Это может занять         │
│    несколько часов: ваша команда тестов выполняется несколько раз на 1       │
│    воркере.                                                                  │
│    PW_PERF_MODE=thresholds npm run e2e:qa                                    │
│                                                                              │
│ 2. Скачайте файлы порогов из артефактов CI: запуск порогов также копирует их │
│    в папку отчёта reports/pw-perf. Примеры для CI: docs/ci.md.               │
│                                                                              │
│ 3. Закоммитьте их: pw-perf-thresholds.json, pw-perf-thresholds.steps.json.   │
│                                                                              │
│ 4. С этого момента запускайте тесты этой командой; она завершается с ошибкой │
│    при регрессии:                                                            │
│    PW_PERF_MODE=test npm run e2e:qa                                          │
│    Результаты: reports/pw-perf/report.html; подробности кода выхода:         │
│    reports/pw-perf/outcome.json.                                             │
