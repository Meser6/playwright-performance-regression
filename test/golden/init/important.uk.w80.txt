│                                                                              │
│ 1. Обчисліть пороги в CI, у тому середовищі, де запускатимуться тести (час,  │
│    виміряний на ноутбуці, не переноситься). Це може тривати кілька годин:    │
│    ваша команда тестів виконується кілька разів на 1 воркері.                │
│    PW_PERF_MODE=thresholds npm run e2e:qa                                    │
│                                                                              │
│ 2. Завантажте файли порогів з артефактів CI: запуск порогів також копіює їх  │
│    у папку звіту reports/pw-perf. Приклади для CI: docs/ci.md.               │
│                                                                              │
│ 3. Закомітьте їх: pw-perf-thresholds.json, pw-perf-thresholds.steps.json.    │
│                                                                              │
│ 4. Відтепер запускайте тести цією командою; вона завершується помилкою при   │
│    регресії:                                                                 │
│    PW_PERF_MODE=test npm run e2e:qa                                          │
│    Результати: reports/pw-perf/report.html; подробиці коду виходу:           │
│    reports/pw-perf/outcome.json.                                             │
